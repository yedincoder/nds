# DESCRIPTION
==============================================================================
LEVEL-01 merupakan tahap System Design NgAppID.
Level ini bertujuan merancang seluruh struktur sistem sebelum masuk ke tahap Project Foundation dan Development.
Pada tahap ini dilakukan perancangan arsitektur aplikasi, database, module, folder structure, dan UI/UX agar proses pengembangan memiliki standar yang konsisten, scalable, secure, dan mudah dipelihara.
Tidak diperbolehkan melakukan implementasi coding sebelum seluruh desain sistem pada LEVEL-01 selesai.
==============================================================================
OBJECTIVE
==============================================================================
Mendefinisikan:

1. System Architecture.
2. Database Architecture.
3. Module Architecture.
4. Folder Structure.
5. UI/UX Design.
6. Application Flow.
7. Data Flow.
8. Component Structure.
9. Development Standard.
10. System Design Documentation.
==============================================================================
SYSTEM DESIGN PRINCIPLE
==============================================================================
Design harus mengikuti:

1. Architecture First.
2. Security First.
3. Performance First.
4. Scalability.
5. Maintainability.
6. Reusable Component.
7. Clean Structure.
