# ==============================================================================
# CODING RULE
# ==============================================================================
Semua kode harus:
- Mengikuti PSR-12.
- Mengikuti Coding Standard CodeIgniter 4.
- Menggunakan Clean Code.
- Menggunakan SOLID jika diperlukan.
- Menggunakan DRY.
- Menggunakan KISS.
- Menggunakan Separation of Concern.
Tidak boleh membuat kode asal berjalan.

# CONTROLLER RULE
# ==============================================================================
Controller hanya bertugas:

- Memanggil validation.
- Memanggil service.
- Mengembalikan response.

- Business logic panjang.
- Manipulasi data kompleks.
# ==============================================================================
# SERVICE RULE
# ==============================================================================

- Business Logic.
- Workflow.
- Calculation.
- Transaction.
- External API.
# ==============================================================================
# MODEL RULE
# ==============================================================================
