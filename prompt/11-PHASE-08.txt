# DESCRIPTION
==============================================================================
Phase-08 merupakan tahap perancangan User Interface dan User Experience project NgAppID.
Phase ini bertujuan menentukan konsep desain, struktur halaman, komponen UI, pengalaman pengguna, dan standar tampilan sebelum memasuki tahap Project Foundation.
Pada Phase ini TIDAK BOLEH membuat kode frontend.
Seluruh keputusan UI/UX menjadi acuan implementasi frontend pada Phase berikutnya.
