# DESCRIPTION
==============================================================================
Phase-13 merupakan tahap pembangunan Content Management System (CMS) NgAppID.
Phase ini bertujuan menyediakan sistem pengelolaan konten website secara dinamis yang dapat digunakan Administrator untuk mengatur halaman, artikel, media, menu, dan informasi website.
CMS menjadi pusat pengelolaan konten publik dan mendukung kebutuhan website profesional.
Seluruh implementasi harus mengikuti Architecture, Database, Module, Authentication, dan Authorization Standard.
