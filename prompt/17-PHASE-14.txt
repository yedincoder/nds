# DESCRIPTION
==============================================================================
Phase-14 merupakan tahap pembangunan Product Management System NgAppID.
Phase ini bertujuan menyediakan sistem pengelolaan produk digital yang dapat digunakan Administrator untuk mengatur informasi produk, harga, kategori, file digital, status produk, dan kebutuhan penjualan.
Product Module menjadi dasar untuk proses Ecommerce pada Phase berikutnya.
Seluruh implementasi harus mengikuti Architecture, Database, Module, Authentication, Authorization, dan CMS Standard.
