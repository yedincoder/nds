# DESCRIPTION
==============================================================================
LEVEL-09 merupakan tahap Deployment NgAppID.
Level ini bertujuan mempersiapkan infrastruktur server, melakukan konfigurasi production environment, melakukan deployment aplikasi, serta menyediakan sistem monitoring agar aplikasi berjalan stabil dan aman pada lingkungan production.
Deployment Level menjadi tahap transisi dari aplikasi hasil development menuju sistem production yang siap digunakan oleh pengguna.
Seluruh implementasi harus mengikuti Server Standard, Production Deployment Standard, Security Standard, dan Monitoring Standard.
