# DESCRIPTION
==============================================================================
Phase-07 merupakan tahap pendefinisian struktur folder project NgAppID.
Phase ini bertujuan menentukan organisasi file, module, component, dan resource agar project memiliki struktur yang konsisten, mudah dipahami, mudah dikembangkan, dan mudah dipelihara.
Pada Phase ini TIDAK BOLEH membuat kode.
Struktur folder yang dibuat pada Phase ini menjadi standar seluruh implementasi project.
==============================================================================
OBJECTIVE
==============================================================================
Mendefinisikan:
1. Project Root Structure.
2. Application Structure.
3. Module Structure.
4. Backend Structure.
5. Frontend Structure.
6. Database Structure.
7. Public Asset Structure.
8. Storage Structure.
9. Documentation Structure.
10. Testing Structure.
==============================================================================
FOLDER PRINCIPLE
==============================================================================
Struktur folder harus mengikuti:
1. Clean Architecture.
2. Modular Development.
3. Separation of Concern.
4. Consistent Naming.
5. Maintainable Structure.
6. Scalable Organization.
7. Documentation First.

NAMING CONVENTION
==============================================================================
Folder:
Menggunakan PascalCase atau lowercase sesuai framework.

Menggunakan PascalCase.
Class:
Menggunakan PascalCase.
Method:
Menggunakan camelCase.
Database:
Menggunakan snake_case.
==============================================================================
FOLDER SECURITY RULE
==============================================================================
1. File konfigurasi tidak boleh berada pada public folder.
2. Upload file harus melalui storage.
3. Folder writable harus memiliki permission sesuai kebutuhan.
4. Source code tidak boleh dapat diakses langsung.
5. Environment file harus aman.
==============================================================================
FOLDER DEVELOPMENT RULE
==============================================================================
RULE-001 : Setiap module wajib memiliki struktur standar.
RULE-002 : Tidak boleh membuat folder tanpa fungsi jelas.
RULE-003 : Tidak boleh menyimpan file random pada root.
RULE-004 : Setiap perubahan struktur harus terdokumentasi.
RULE-005 : Struktur folder harus konsisten seluruh project.
