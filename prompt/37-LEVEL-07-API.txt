# DESCRIPTION
==============================================================================
LEVEL-07 merupakan tahap pembangunan API System NgAppID.
Level ini bertujuan menyediakan layanan komunikasi antara aplikasi internal maupun eksternal melalui REST API yang aman, terstruktur, scalable, dan mudah dikembangkan.
API Layer menjadi penghubung antara backend NgAppID dengan aplikasi pihak ketiga, mobile application, frontend application, payment gateway, dan layanan eksternal lainnya.
Seluruh implementasi harus mengikuti API Architecture, Security Standard, Authentication Standard, Documentation Standard, dan Performance Standard.
