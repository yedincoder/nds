# DESCRIPTION
==============================================================================
LEVEL-02 merupakan tahap Project Foundation NgAppID.
Level ini bertujuan membangun pondasi awal project sebelum masuk ke tahap Core Module Development.
Pada tahap ini dilakukan inisialisasi project, konfigurasi environment, implementasi authentication, dan authorization sebagai dasar keamanan serta pengelolaan akses sistem.
Seluruh implementasi harus mengikuti standar arsitektur, coding standard, security standard, dan development workflow yang telah ditentukan pada NDS.
