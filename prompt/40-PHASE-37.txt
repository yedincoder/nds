# DESCRIPTION
==============================================================================
Phase-37 merupakan tahap Security Audit NgAppID.
Phase ini bertujuan melakukan pemeriksaan menyeluruh terhadap keamanan aplikasi sebelum masuk tahap Deployment.
Security Phase memastikan seluruh modul, database, API, authentication, authorization, server, dan data pengguna memiliki perlindungan yang sesuai dengan standar keamanan aplikasi modern.
Seluruh implementasi harus mengikuti Security Best Practice, OWASP Standard, CodeIgniter Security Standard, dan Production Security Requirement.
