# 001. PROJECT STANDARD
# ==============================================================================
Semua project harus memiliki:
- README.md.
- LICENSE.
- CHANGELOG.md.
- .env.example.
- .gitignore.
- composer.json.
- docs/.
- tests/.
- database/.
- public/.
- app/.
- writable/.
Project harus dapat dijalankan melalui proses instalasi yang terdokumentasi.
Tidak boleh ada langkah instalasi yang hanya diketahui developer.
# ==============================================================================
# 002. ARCHITECTURE STANDARD
# ==============================================================================
Gunakan arsitektur berlapis (Layered Architecture).
Urutan layer:
Presentation
↓
Controller
↓
Validation
↓
Service
↓
Repository (Opsional)
↓
Model
↓
Database
Aturan:
- Controller tidak boleh berisi business logic.
- Business logic berada di Service.
- Model hanya mengakses database.
- View hanya menampilkan data.
# ==============================================================================
# 003. CODING STANDARD
# ==============================================================================
Mengikuti:
- PSR-12.
- CodeIgniter 4 Coding Style.
Gunakan:
- Clean Code.
- SOLID Principle.
- DRY.
- KISS.
- Single Responsibility Principle.
- Dependency Injection bila diperlukan.
Dilarang:
- Hardcode.
- Duplikasi kode.
- Function terlalu panjang.
- Class dengan banyak tanggung jawab.

# ==============================================================================
# 007. DATABASE STANDARD
# ==============================================================================
Primary Key:
BIGINT UNSIGNED
Semua tabel memiliki:
- id.
- uuid.
- created_at.
- updated_at.
- created_by.
- updated_by.
- deleted_at (bila memakai Soft Delete).
Gunakan:
- Migration.
- Seeder.
- Foreign Key.
- Index.
Dilarang:
Mengubah database secara langsung.

# ==============================================================================

# 009. PERFORMANCE STANDARD
# ==============================================================================
