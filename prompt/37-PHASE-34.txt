# DESCRIPTION
==============================================================================
Phase-34 merupakan tahap pembangunan REST API System NgAppID.
Phase ini bertujuan menyediakan layanan API standar yang memungkinkan komunikasi antara sistem NgAppID dengan aplikasi eksternal, frontend application, mobile application, dan layanan pihak ketiga.
REST API harus memiliki struktur yang konsisten, aman, scalable, mudah dikembangkan, dan memiliki dokumentasi yang jelas.
Seluruh implementasi harus mengikuti API Architecture, Security Standard, Performance Standard, dan Documentation Standard.

API ENDPOINT STRUCTURE
==============================================================================
