# DESCRIPTION
==============================================================================
Phase-19 merupakan tahap pembangunan Checkout System NgAppID.
Phase ini bertujuan menyediakan proses pemesanan dari Cart menjadi Order sebelum masuk ke proses Billing dan Payment.
Checkout Module bertanggung jawab memastikan data pelanggan, produk, layanan, harga, dan informasi transaksi telah valid sebelum transaksi dibuat.
Seluruh implementasi harus mengikuti Architecture, Database, Module, Authentication, Authorization, Security, dan Ecommerce Standard.
