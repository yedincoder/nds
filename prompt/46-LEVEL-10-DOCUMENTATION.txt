# DESCRIPTION
==============================================================================
LEVEL-10 merupakan tahap Documentation NgAppID.
Level ini bertujuan membuat seluruh dokumentasi sistem agar aplikasi mudah digunakan, dikembangkan, dipelihara, dan diintegrasikan oleh pengguna, developer, administrator, maupun pihak eksternal.
Documentation Level menjadi tahap akhir dalam siklus pengembangan project untuk memastikan seluruh pengetahuan sistem terdokumentasi dengan lengkap.
Seluruh dokumentasi harus mengikuti Documentation Standard, Technical Writing Standard, dan Knowledge Management Standard.
