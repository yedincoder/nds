# DESCRIPTION
==============================================================================
Phase-40 merupakan tahap persiapan dan konfigurasi Server NgAppID.
Phase ini bertujuan menyiapkan infrastruktur server yang akan digunakan untuk menjalankan aplikasi NgAppID pada lingkungan production.
Server harus memiliki konfigurasi yang aman, stabil, optimal, dan sesuai dengan kebutuhan aplikasi CodeIgniter 4, MariaDB, Redis, dan Nginx.
Seluruh implementasi harus mengikuti Server Standard, Security Standard, Performance Standard, dan Infrastructure Requirement.
