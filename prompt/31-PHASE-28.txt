# DESCRIPTION
==============================================================================
Phase-28 merupakan tahap pembangunan Admin Dashboard NgAppID.
Phase ini bertujuan menyediakan pusat monitoring dan kontrol bagi Administrator dan Super Administrator untuk melihat kondisi sistem, aktivitas pengguna, transaksi bisnis, performa aplikasi, dan informasi penting lainnya.
Admin Dashboard menjadi halaman utama setelah administrator berhasil melakukan authentication.
Seluruh implementasi harus mengikuti Architecture, Authorization, Security, Performance, UI/UX, dan Admin Panel Standard.
